# SABLE engine lock — 2026-11-21

**Web-Native Core (WebGL / 3D Canvas / Web Workers).** No Gemini. No cloud VLM on the ship path.

- **Dropped**: Godot 4.7 (toolchain bloat, GDExtension compile friction, OS capture fragmentation) and Unity (proprietary editor lock-in, 50 GB footprint).
- **Target Architecture**: Pure web-native client (`proto/` and web client) on the ship floor: Chromium on a MacBook Pro–class lid camera.
- **Tracking**: In-browser `getUserMedia` (720p/1080p), MediaPipe Hands-class (landmark 8) interim, skin/NCC else path, One Euro pointing filter. Fire peeks the latest `AimSample` on AimBus — never waits on a camera frame. Product shoot is shark-fin (thumb UP). Thumb parallel is SAFE. Index+middle ceiling is charger-plug reload. HID / trackpad click is DESKTOP / forceGun emergency only (non-product) — never the product shot.
- **Modes**:
  - **Yard / Gallery**: 60s physical ADS arcade. The Yard is the sole active map.
  - **Bay**: parked (not player-facing). Not a live 1v1 mode.
- **Floor**: 1080p60 on integrated graphics / GTX 1650; 1080p120 on modern GPUs. Zero install required. Ship browser is Chromium.
- **Native kernels**: Mojo 1.0 via Pixi (`native/mojo`) — One Euro, spatial moments, 3D hitscan.
