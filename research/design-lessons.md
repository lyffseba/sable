# SABLE — public design lessons (original IP only)

See executor memo 2026-09-01. Key lock-ins:

- Loop: strafe on pad → lift (physical ADS) → click fire → drop-strafe. Halo 30s of fun.
- Broadcast the lift: ghost aim-ray, pad/air state, no tutorial wall. First kill < 60s on Range.
- Ranked ≠ live ops. No bloom/RNG on the lifted shot. Cosmetics never affect tracking.
- v1 modes only: Range (offline), 1v1 Duel, 2v2 Arena. One arena, two guns, melee.
- Input class: webcam quality gate, signed calib, no virtual cams in ranked.
- Timing contract: 128 Hz sim or timestamped lift/fire, published latency.
- No Fortnite/CS2/Halo/Combat Master IP, maps, guns, or code.
